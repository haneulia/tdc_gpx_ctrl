Frame / Data 계산 (D00 → D09)

Item / 항목Result / 결과Unit / 단위Formula or meaning / 계산식 또는 의미
계산 경로: D00에서 motor·laser·TDC 사이 값의 소유권과 전달 방식을 먼저 확정합니다. D01→D02에서 유효 거리 sample 수를 확정하고 D02A에서 GPX FIFO readout 소유권을 확인합니다. D03에서 cell, source beat, canonical 32-bit word를 구분합니다. D04에서 slope별 cell slot과 VDMA HSIZE·VSIZE·STRIDE를 확정하고, D05에서 구현된 packed RTL과 이전 full-keep 구조를 폭별로 비교합니다. VDMA 정렬 byte는 Distance packets에 포함하지 않으며, D06→D09는 D02의 유효 sample 수로 Ethernet word, packet 수, 전송 시간과 margin을 계산합니다.

Ethernet Repack 크기 계산 (R01 → R22)

순서계산 단계대입식결과검증 의미
계산 순서는 Face scan 결과가 생성된 뒤 Ethernet application payload가 만들어지는 시간순입니다. 첫 MTU는 Face Header 전용이며, 거리 데이터는 두 번째 MTU부터 시작합니다. UDP/TCP/IP Header는 계산에서 제외합니다.

판단 근거 (V01 → V04)

항목판단근거
거리별 포인트 간격은 목표면이 평면이고 중앙 근처에서 각 분해능이 작다는 가정의 chord 근사입니다. 실제 광학 왜곡, 렌즈, mirror alignment, APD 배열 각도는 별도 보정 대상입니다.

Optical diagnostics / 광학 진단 (O01 → O04)

항목값의미
입사 광원 방위각은 광원 기준 위치를 정하고, 입사 ray는 그 반대 방향으로 미러를 향해 진행합니다. `입사 Y offset`은 좌표 평면에서 위/아래 평행 이동입니다. 기하 진단은 물리 단위 mm로 표시합니다. 정N각 다면미러는 중심-미러면 수직거리 rho를 입력값으로 사용하고, 외접 반경 R = rho / cos(pi/N), 한 면 길이 L = 2rho tan(pi/N) 관계를 사용합니다. 중심선이 꼭짓점에 걸리면 specular reflection은 정의되지 않으므로 광학 진단에서 CHECK로 표시됩니다.
