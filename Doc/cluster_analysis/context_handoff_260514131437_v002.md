## 2. Vivado/xsim 산출물 표준 구조

Vivado/xsim 실행 산출물은 루트 디렉터리에 계속 남기지 않고 아래 구조로 이동 보관한다.

```text
sim_results/
  vivado_xsim/
    README.md
    sessions/
      <YYMMDDHHMMSS>_<label>/
        logs/
          compile/     xvlog, xvhdl log
          elaborate/   xelab log
          simulate/    xsim log
          vivado/      Vivado batch/project log
          journal/     *.jou
        waves/         *.wdb
        work/          *.pb, xsim.dir, .Xil, legacy sim work dirs
        tmp/           script-generated temporary files
        crash/         hs_err_pid*.log/dmp
        manifest.csv
        README.md
```

`sim_results/vivado_xsim/sessions/`는 `.gitignore`에 포함되어 있으므로 Git에 넣지 않는다. Git에는 정책 문서와 정리 스크립트만 포함한다.

## 4. 정리 스크립트 계약

정리 스크립트:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\archive_vivado_xsim_outputs.ps1 -Stamp <YYMMDDHHMMSS> -Label <run_label>
```

주요 계약:

| 항목 | 계약 |
|---|---|
| 기본 정책 | 삭제가 아니라 session 폴더로 이동 보관 |
| 추적성 | `manifest.csv`에 원본 경로, 이동 경로, category, size, last write time 기록 |
| 안전성 | Git tracked file과 tracked descendant를 가진 directory는 이동하지 않음 |
| 실패 처리 | regression script의 `finally`에서 archive 호출 |
| nested regression | 하위 script는 `-NoArchiveOnExit`, 최상위 script가 한 번만 archive |
| 수동 정리 | legacy `sim_*` directory까지 정리할 때 `-IncludeLegacySimDirs` 사용 |

## 7. 루트 정리 상태

마지막 확인 기준으로 루트에는 Vivado/xsim 생성물 이름 패턴 중 `sim_results`만 남아 있었다.

확인 명령:

```powershell
Get-ChildItem -Path . -Force | Where-Object {
  $_.Name -match '^(xsim\.dir|\.Xil|tmp|sim_|xvhdl|xvlog|xelab|xsim|vivado)' -or
  $_.Name -match '\.(jou|wdb|pb|log)$'
} | ForEach-Object { $_.Name }
```

기대 결과:

```text
sim_results
```

## 9. 다음 작업자 판단 기준

다음 세션에서 Vivado/xsim을 실행하거나 검증 결과를 문서화할 때는 아래를 유지한다.

| 판단 항목 | 유지 규칙 |
|---|---|
| 문서 근거 | session archive 경로와 log 파일, 필요한 경우 line 근거까지 기록 |
| Git 관리 | script, RTL, TB, Markdown/PPT 산출물은 commit 대상. `sessions/` 아래 실행 산출물은 commit 제외 |
| 실패 로그 | 실패한 실행도 archive하고, 실패 session을 문서 근거로 남김 |
| 삭제 여부 | 기본은 삭제가 아니라 이동 보관. 삭제가 필요한 경우 사용자 승인 후 진행 |
| 신규 스크립트 | `finally`에서 `archive_vivado_xsim_outputs.ps1` 호출 |
| 직접 Vivado GUI 실행 | GUI가 만든 산출물도 세션 종료 후 archive script로 정리 |
